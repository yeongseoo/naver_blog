키워드 확장 도구 v1

시드 키워드 → 네이버 자동완성 10개 수집 → 저장 → 확장

⚙️ AI(Gemini) 설정
키는 이 브라우저(chrome.storage)에만 저장됩니다. 모델 예: gemini-3.6-flash · 글쓰기 주소를 넣으면 열린 글쓰기 탭이 없을 때 자동으로 백그라운드로 엽니다.
🧩 생성 프롬프트 (prompt.md 에서 불러옴 · 편집 전용 코드창)
프롬프트 원본은 확장 폴더의 prompt.md 파일입니다. 파일을 직접 고쳐도 되고, 아래 코드창에서 고쳐 [프롬프트 저장] 하면 그 내용이 우선 적용됩니다. [기본값으로] 를 누르면 prompt.md 를 다시 불러옵니다.
이 프롬프트로 Gemini가 글을 만듭니다. 자리표시자 {keyword}, {imageCount} 는 생성 시 자동 치환됩니다.
구분선 style 사용 가능: default(기본 실선) · line1 · line5 · line6 · line7  예: { "type": "divider", "style": "line1" }
✍️ AI 글 생성 (테스트)
※ 네이버 로그인만 돼 있으면 됩니다. 글쓰기 페이지가 없으면 백그라운드로 몰래 열고 저장 후 닫습니다. (해당 탭 F12는 닫아 두세요.)
