# 블로그 오토포스터 (데스크톱 앱)

네이버 블로그 **예약 자동발행** Windows 데스크톱 앱. 실제 발행/자동화는 Chrome 확장이
사용자의 로그인 세션으로 수행하고, 이 앱은 **글 작성·예약·상태 관리 컨트롤 패널** 역할을 한다.
앱과 확장은 로컬 WebSocket(`ws://127.0.0.1:8765`)으로 통신한다.

```
┌─────────────┐   localhost WS    ┌──────────────────┐   RabbitWrite    ┌────────────┐
│ 데스크톱 앱  │ ───(발행 작업)──▶ │ Chrome 확장(#35) │ ───(로그인세션)─▶ │ 네이버 블로그 │
│ (Electron)  │ ◀──(발행 결과)─── │  background.js   │                  └────────────┘
└─────────────┘                   └──────────────────┘
```

## 개발 실행

```bash
cd desktop
npm install     # 최초 1회 (Electron 다운로드)
npm start       # 앱 실행
npm run dev     # DevTools 열고 실행
```

## 설치파일(.exe) 빌드 — 판매 배포용

```bash
npm run dist    # release/ 에 NSIS 설치파일 생성 (Windows x64)
```

> 아이콘: `build/icon.ico` 를 넣으면 앱/설치파일 아이콘으로 사용된다. 없으면 기본 Electron 아이콘.

## 연동 순서

1. Chrome `chrome://extensions` → 개발자 모드 → `../extension` 폴더 로드 (빌드 #35 이상)
2. Chrome에서 네이버 로그인 (세션 유지)
3. 이 앱 실행 → 좌측 하단 표시등이 초록색이면 연결 완료
4. [글 작성]에서 제목·블록 작성 → [예약 등록] 또는 [지금 발행]
